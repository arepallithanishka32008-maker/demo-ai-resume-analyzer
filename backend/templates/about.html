About AI Resume Analyzer

AI Resume Analyzer is a web application developed using HTML, CSS, JavaScript, Python and Flask.


It helps students and job seekers analyze resumes using AI by providing:

  • ✅ ATS Score
  • ✅ Resume Skill Detection
  • ✅ Missing Skills Analysis
  • ✅ AI Suggestions
  • ✅ Interview Questions

Our goal is to help users create professional resumes and improve their chances of getting shortlisted.
